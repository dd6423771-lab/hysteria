## 五、遗留与边界

- UDP 路径（每包查 KickMap）未单独造流量验证，但 kickall 走的是 QUIC 连接级 `CloseWithError`，TCP/UDP 会话同连同亡，代码路径一致。
- 注册表只覆盖**已认证**连接；正在握手的未认证连接不受影响（符合预期：认证拒绝由面板 hy2-auth 层负责）。
- kickall 与新连接认证之间无原子性：`closed=N` 返回后新认证的连接不会被本调用波及（无代际标记），面板如需"冻结窗口"可先拒绝认证再 kickall。
